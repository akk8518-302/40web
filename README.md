# 國小四年級國語科互動式學習網頁教學指引手冊

歡迎使用專為臺灣國小四年級設計的**「國小國語科互動式學習網頁」**！
本系統以康軒／翰林／南一版國小四年級國語第七課**《到此「藝」遊》**（作者：陳碏）教材為基礎，依循 108 課綱核心素養標準，為現場教師量身打造。

---

## 📂 一、網頁檔案結構與存放位置

本專案已完整建立於專案資料夾中，路徑如下：

```
c:\Users\user\Desktop\國語互動網頁\reading-app\
│
├── index.html              <-- 主網頁程式檔（雙擊即可直接在瀏覽器開啟）
├── style.css               <-- 介面樣式表（大字體、高對比、護眼溫馨配色）
├── lesson-data.js          <-- 【獨立教材與題庫資料檔】（抽換課文只要改這裡！）
├── app.js                  <-- 互動學習引擎（音效合成、語音朗讀、點選配對、句子重組、闖關計分）
├── .nojekyll               <-- 確保 GitHub Pages 靜態檔案正常載入
└── README.md               <-- 本教師指引手冊
```

> **📌 GitHub Pages 發布說明**：
> 所有網頁核心檔案（`index.html`、`style.css`、`lesson-data.js`、`app.js`）皆已統一配置於同一層目錄，路徑引用直接對應，無論是在本機資料夾雙擊開啟，或是上傳至 GitHub 倉庫根目錄，皆能 100% 正常載入樣式與互動腳本！

## 🚀 二、如何直接開啟與課堂使用

### 1. 教師投影使用（桌機 / 筆電）
1. 打開資料夾：`c:\Users\user\Desktop\國語互動網頁\reading-app\`
2. **對著 `index.html` 連點滑鼠左鍵兩下（Double Click）**。
3. 系統會自動以預設瀏覽器（如 Microsoft Edge 或 Google Chrome）開啟。
4. **投影機專用模式**：
   - 點擊右上角 **「🔍 教室投影大字」** 按鈕，文字會自動放大至適合教室後排學生觀看的 23px 超大字體。
   - 支援全螢幕快捷鍵（按下鍵盤 `F11`），即可消除網頁邊框，變身專業電子白板互動教學軟體！

### 2. 教室平板或學生觸控操作
- 系統全域支援**觸控點選**（Touch-friendly），所有按鈕、生字卡、詞語配對皆具備大觸控區，學生用手指輕點即可作答。
- 內建 **Web Audio 離線音效** 與 **瀏覽器繁體中文語音朗讀（TTS）**，點擊段落朗讀或生字卡即可聽取標準發音。

## 🎒 三、如何把網頁交給學生使用

因為本系統是**純單機、無後端、無外部付費 API、完全零依賴**的綠色網頁，分發給學生非常簡單：

1. **隨身碟 / 學校共用資料夾（最推薦）**：
   - 將整份 `reading-app` 資料夾複製到隨身碟，或放至學校電腦教室的「共用資料夾（公用磁碟機）」。
   - 學生打開電腦，雙擊資料夾內的 `index.html` 就能立即操作。
2. **平板電腦（iPad / Android 平板）**：
   - 將 `reading-app` 資料夾壓縮為 `.zip` 檔，透過 AirDrop、Line 或 Google Classroom 傳送給學生解壓縮開啟。
3. **雲端硬碟 / 學校網站託管**：
   - 教師可將 `reading-app` 資料夾上傳至學校的靜態網頁空間或 GitHub Pages，學生只要點擊一個網址連結即可跨平台自主學習。

## 🔄 四、未來製作下一課：如何只替換教材與題庫？

為了讓老師未來每一課都能重複使用，**「網頁版型與互動引擎」** 和 **「教材題庫」** 已完全分開（解耦設計）。未來製作第八課或下一單元時，**不需要重寫任何 HTML 或 CSS**，只要照著以下三步驟：

### 步驟 1：開啟 `reading-app/js/lesson-data.js`
使用任何純文字編輯器（如「記事本」、VS Code 或記事本軟體）開啟 `js/lesson-data.js`。

### 步驟 2：填入下一課的課文資訊
檔案內部有非常清晰的中文標註，老師只需將引號中的內容替換為新課文：

```javascript
const LESSON_DATA = {
  meta: {
    grade: "國小四年級",
    unit: "第參單元 小小觀察家",
    lessonNumber: "第八課",                // 替換：課次
    title: "四季的頭髮",                   // 替換：新課名
    author: "...",                       // 替換：作者
    textType: "童詩",                     // 替換：文體
    summary: "...",                      // 替換：大意
    coreConcept: "..."                   // 替換：核心素養
  },
  preQuestions: [ /* 課前思考題 */ ],
  paragraphs: [ /* 分段內容與空間/時間標籤 */ ],
  characters: [ /* 生字部首、筆畫、注音、例句 */ ],
  words: [ /* 重要語詞與解釋 */ ],
  polyphones: [ /* 多音字辨析 */ ],
  sentenceKnowledge: [ /* 句型結構與修辭 */ ],
  adventureStages: [ /* 闖關關卡題目與選項 */ ]
};
```

### 步驟 3：儲存檔案並重新整理網頁
儲存 `lesson-data.js` 後，在瀏覽器按下 `F5`（或重新整理），整個網頁就會自動換成全新一課的內容，所有的配對、朗讀、重組與闖關系統都會自動生效！
